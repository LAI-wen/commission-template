# 03. 功能規格與 PRD (Functional Spec & PRD)

## 1. 創作者站點功能
*   **個人名片 (Profile)**：展示頭像、簡介、風格標籤、接案狀態。
*   **作品集 (Portfolio)**：Masonry 網格排列，支援燈箱 (Lightbox) 放大。
*   **委託清單 (Commissions)**：列出所有委託項目、價格、預估工期。
*   **智慧委託表單**：根據規格（半身/全身、商業/個人）自動累計價格。
*   **進度查詢頁**：委託人無需登入，透過 Email/Link 查詢排單位置。

## 2. 創作者後台 (Dashboard)
*   **Inbox**：集中處理所有委託申請與詢問。
*   **Queue 管理**：看板式介面 (Kanban)，拖曳調整排單順序。
*   **作品管理**：上傳作品、設定封面、分類標籤。
*   **編輯器 (Layout Editor)**：
    *   區塊拖曳排序。
    *   區塊內容編輯。
    *   全域主題設定 (顏色、字型、背景)。

## 3. 聚合平台 (Hub)
*   **創作者探索**：依標籤、風格、價格搜尋。
*   **開放通知**：委託人可追蹤繪師，獲取開單推播。
*   **委託項目聚合**：直接預覽所有繪師目前的委託項目摘要。

## 4. 關鍵狀態機：委託流程
1.  **Submitted**：委託人送出申請。
2.  **Accepted**：創作者確認接單並報價。
3.  **Queued**：委託人付款（由創作者自行處理金流），進入排單。
4.  **Draft**：創作者上傳草稿。
5.  **Revision**：委託人回饋修改意見。
6.  **Final/Completed**：交付完稿。

## 5. 成功指標 (North Star Metrics)
*   **創作者端**：部署成功率、每月活躍管理數 (DAU)。
*   **委託人端**：表單完成率、收藏/追蹤率。
